# Command Code Desktop

다른 환경에서 이어서 개발하려면 [HANDOFF.md](HANDOFF.md)부터 읽으세요.
현재 구현, 알려진 검증 경계, 오프라인 검사와 AI 실행계획의 시작점이 정리돼 있습니다.

Command Code CLI를 GUI 앱처럼 쓰는 Windows 데스크톱 앱입니다 (Tauri 2).
폴더를 고르면 바로 대화가 시작되고, 터미널도 `cd`도 필요 없습니다.

```
┌ 사이드바 ─────┬ [채팅: 버그 수정] [채팅: 새 대화] [터미널] [+] ─────────────────┐
│ + 새 채팅     │ cmdc-gui        [표준 ▾] [Claude Sonnet 5.5 ▾] [high ▾] ▮▮▯ 21% │
│ 프로젝트       │                                                        │
│ ▾ cmdc-gui   │                     README에 설치 방법 추가해 줘  (사용자)     │
│   대화 A  2시간│  ▸ Read README.md                                  [완료]   │
│   대화 B  1일  │  ▾ Edit README.md                        +5 −0     [완료]   │
│ ▸ anki       │     (diff)                                                │
│              │  ⛨ 권한 요청  $ pnpm test   [1 한 번 허용] [2 항상] [3 거부]   │
│ ⚙ 설정        │  [ 무엇을 할까요? ( / 명령 · 이미지 붙여넣기 )          → ]      │
└──────────────┴────────────────────────────────────────────────────────┘
```

## 기능

- **채팅 탭 (ACP)**: `cmd acp`(Agent Client Protocol)로 CLI와 대화합니다.
  - 마크다운·코드 하이라이트 답변, 접을 수 있는 "생각" 블록
  - **수식(LaTeX)**: `$…$`, `$$…$$`, `\(…\)`, `\[…\]`를 KaTeX로 렌더링 (인터넷 연결 불필요). 수식을 두 번 클릭하면 LaTeX 원문이 복사됩니다. 가격(`$5`)이나 코드 속 `$`는 수식으로 바꾸지 않고, 잘못된 수식은 빨간 원문으로 보여 줍니다.
  - **수식 입력**: 입력창에 수식을 쓰면 입력창 위에 렌더링된 모양이 바로 뜨고(`$$` 블록은 닫기 전에도), 보낸 뒤 내 말풍선에도 수식으로 보입니다. `∑` 버튼은 선택한 글을 `$…$`로 감싸고, Shift+클릭은 `$$` 블록을 넣습니다. 미리보기는 설정에서 끌 수 있습니다.
  - **문서형 프롬프트**: 제목·목록·표가 있는 마크다운 문서를 붙여 넣으면 미리보기가 칩 대신 전체 문서로 바뀌고(커서 위치를 따라 스크롤), 보낸 뒤 내 말풍선도 마크다운으로 그려집니다. 말풍선의 "원문" 버튼으로 보낸 그대로를 볼 수 있습니다. 옵시디언 `![[그림.png]]` 첨부는 "첨부 이미지 자리"로 표시되고 보내는 글은 바뀌지 않습니다.
  - 도구 실행 카드 (읽기/수정/검색/명령 실행), 파일 수정은 diff로, 경로 클릭 시 파일 열기
  - 권한 요청은 버튼 또는 숫자 키 `1`~`4`로 응답. 에이전트의 질문(계획 모드로 갈지 등)은 "질문" 카드에 선택지 그대로 보입니다.
  - **권한 무시 모드**: CLI는 이 모드에서도 위험 표시가 붙은 요청(작업 폴더 밖 삭제, `permissions.ask` 규칙 등)과 계획 모드 진입은 묻습니다. 앱이 평범한 요청은 바로, 위험 요청은 5초 카운트다운 뒤 자동 허용합니다. 에이전트의 질문도 5초 뒤 첫 번째 답(보통 추천 답)을 고릅니다. 카운트다운 중에는 "자동 선택 멈추기"로 직접 고를 수 있습니다.
  - 할 일(todo) 진행률 패널, 컨텍스트 사용량 게이지
  - **ULTRAWORK DAG**: `mass ulw`·`ulw-loop`·`mass replica`가 만든 실행 그래프를 채팅 위에 파도(의존 단계)별로 그립니다. `ulw_plan`·`ulw_node`·`ulw_verify`와 서브에이전트 호출을 읽어 상태·의존성·검증 결과를 보여 주고, 지난 대화를 열어도 기록에서 그대로 복원합니다. 헤더의 `ULW` 칩으로 열고 닫고, 패널 머리를 눌러 접습니다.
  - 모드(표준/편집 자동 허용/계획/묻지 않기/권한 무시)·모델·추론 강도 드롭다운, `Shift+Tab`으로 모드 순환
  - `/` 명령 자동완성, 이미지 붙여넣기·드래그 앤 드롭
  - 작업 중 입력하면 대기열에 쌓였다가 차례로 전송, `Esc`로 중지
- **지난 대화 이어 하기**: 사이드바에서 프로젝트를 펼치면 그 폴더의 세션 목록이 나옵니다. 클릭하면 기록 파일(`~/.commandcode/projects/…/<id>.jsonl`)을 바로 그려 주고, 뒤에서 세션에 다시 연결합니다.
- **터미널 탭 (TUI)**: 진짜 Command Code TUI를 ConPTY로 띄웁니다. 로그인, `/usage`, `/config`처럼 GUI에 없는 기능용. `Ctrl+C`(선택 시 복사)·`Ctrl+V`·우클릭 지원.
- **끌어다 놓기**: 폴더를 창에 놓으면 프로젝트로 열리고, 이미지를 놓으면 현재 대화에 첨부됩니다.
- **한 창으로**: 앱이 켜져 있을 때 `cmdc-gui.exe D:\project`를 다시 실행하면 새 창 대신 기존 창에 그 폴더가 열립니다. 창 크기·위치는 기억합니다.
- **계정 전환**: 사이드바 아래 계정 버튼에서 클릭 한 번으로 바꿉니다. 자세한 내용은 아래 "계정"을 보세요.
- **알림**: 창이 뒤에 있을 때 응답 완료·권한 요청을 Windows 알림으로 알려 주고, 탭에 점을 표시합니다.
- **설정**: 새 채팅 기본 모드, 보내기 키, 테마(시스템/어둡게/밝게), 터미널 글자 크기.

### 계정

사이드바 아래의 계정 버튼을 누르면 메뉴가 열립니다. 모든 변경은 **바로** 반영됩니다.

- **전환**: 목록에서 계정을 누르면 열려 있는 대화와 터미널까지 모두 그 계정으로 다시 연결됩니다. 대화 내용은 그대로 남고, 채팅 상단에 지금 계정이 표시됩니다. 작업 중인 대화는 그 작업이 끝나는 대로 넘어갑니다.
- **다른 계정으로 로그인…**: 로그인 탭이 열리고 브라우저에서 로그인하면, 로그인 정보가 생기는 즉시 계정이 추가되고 그 계정으로 전환되며 로그인 탭은 저절로 닫힙니다.
- **로그아웃**: 계정마다 있는 "로그아웃" 버튼. CLI 로그인(`cmd login`)은 실제로 `cmd logout`을 실행하고, 저장된 계정은 앱에서 키를 지웁니다. 쓰던 계정에서 로그아웃하면 CLI 로그인 계정으로 자동 전환됩니다.
- **앱 밖의 변화도 반영**: 터미널이나 다른 창에서 `cmd login`/`cmd logout`을 해도 앱이 1초 안에 알아채고, CLI 로그인을 쓰던 대화를 다시 연결합니다.
- 앱이 꺼져서 마무리되지 못한 로그인은 다음 실행 때 자동으로 복구됩니다.

동작 방식: CLI는 `COMMAND_CODE_API_KEY` 환경변수가 있으면 `auth.json`보다 그 키를 먼저 씁니다. 앱은 계정별 키를 **Windows 자격 증명 관리자**에 보관하고 CLI를 실행할 때 그 키만 넘깁니다. 그래서 계정을 바꿔도 대화 기록, 설정, 스킬, git 설정은 그대로 공유됩니다. 키는 Rust 쪽에서만 다루고 화면(웹뷰)으로 넘어가지 않습니다.

### 사용량 게이지

탭 바 오른쪽 위에 항상 사용량 게이지가 떠 있습니다 (사이드바를 접어도 보임). 한도마다 이름을 붙여 보여 주고, 막대는 가장 많이 찬 한도를 따릅니다. 예: `▬▬▭ 5시간 12% · 주간 86% · 월간 45% · $X.XX`

- **월간 한도(이번 달 크레딧)**: 요금제 기본 크레딧 대비 쓴 비율과 남은 금액, 갱신까지 남은 날 (CLI `/usage`와 같은 계산).
- **5시간·일간·주간 한도**: 요금제에 걸린 한도(예: Go는 5시간 $3, 주간 $6)를 사용량 API에서 읽어 각각 보여 줍니다. 서버가 한도를 넘었다고 알려 주거나 답변이 한도 오류로 막히면 게이지가 빨갛게 바뀌며 어느 한도인지(`주간 한도 도달 · 10월 28일 오후 04:23 초기화`)를 보여 줍니다. 오류 메시지에 한도 이름이 없으면 넘친 한도를 계정 사용량에서 찾아 표시합니다.
- 색: 초록(여유) → 노랑(80% 이상) → 빨강(95% 이상, 한도 도달, 잔액 없음).
- 누르면 자세히 보기 · 새로고침 · 사용 가능한 모델 · 계정 전환. 1분마다, 그리고 답변이 끝날 때마다 갱신됩니다.

### 모델 사용 가능 여부

계정마다 쓸 수 있는 모델이 다릅니다. 앱은 계정의 요금제와 잔액을 확인해서 모델 목록을 나눠 보여 줍니다.

- **채팅 상단 모델 목록**: "사용 가능 / 무료 모델 / 요금제 업그레이드 필요 / 크레딧 부족으로 사용 불가"로 묶이고, 쓸 수 없는 모델은 회색으로 비활성화됩니다(이유가 함께 표시됨).
- **계정 메뉴 → 계정별 사용 가능한 모델 보기**: 계정을 골라 모든 모델의 상태를 한눈에 봅니다.
- 쓸 수 없는 계정·모델이면 보내기 전에 경고가 뜨고, "사용 가능한 모델로 바꾸기" 또는 "계정 전환" 버튼이 함께 나옵니다.
- 사이드바와 계정 메뉴에 계정별 "요금제 · 잔액"이 표시됩니다(예: `Go · $X.XX`).

판정 규칙 (CLI의 접근 판정 코드 + 공식 문서 [Pricing & Limits](https://commandcode.ai/docs/resources/pricing-limits)):

1. 잔액이 $0이면 아무 모델도 쓸 수 없습니다.
2. 무료 모델(`:free`)은 요청 비용이 0원이지만, 세션을 시작하려면 **잔액 $1 이상**이 필요합니다.
3. 충전 크레딧이나 보너스 크레딧이 있으면 모든 모델을 쓸 수 있습니다.
4. 그 외에는 요금제 등급이 모델의 최소 요금제 이상이어야 합니다 (Go → GOAT → Pro → Provider → Max → Ultra).

### 업데이트

왼쪽 아래 버전 표시(`앱 0.4.0 · CLI 1.87.1`)를 누르면 업데이트 창이 열립니다. 새 버전이 있으면 "업데이트 있음"이 붙습니다.

- **CLI가 스스로 업데이트되면**: 앱이 15초 안에 버전 변화를 알아채고, 열린 대화를 새 버전으로 다시 연결합니다(대화 내용 유지, 작업 중이면 끝난 뒤). 그리고 아래 호환성 점검을 다시 돌려 문제가 있으면 알려 줍니다.
- **CLI 호환성 점검**: 이 앱이 CLI에서 기대는 기능(계정 키 환경변수, ACP, 세션 불러오기, 모델 최소 요금제, 요금 API, 사용 한도 창, 모델 목록, ACP 프로토콜 버전)을 확인해 ✓/! 로 보여 줍니다. 하나라도 빠지면 버전 표시에 "호환성 확인 필요"가 붙습니다.

- **CLI**: "CLI 업데이트 확인" → 새 버전이 있으면 "CLI 지금 업데이트" (`cmd update`). CLI는 스스로도 백그라운드에서 업데이트하며, 새로 여는 대화부터 새 버전을 씁니다.
- **앱**: 앱은 이 소스 폴더에서 빌드됩니다. 빌드 때의 커밋과 소스 폴더의 최신 커밋을 비교해, 새 커밋이 있으면 변경 내역과 함께 알려 줍니다. "앱 업데이트"를 누르면 백그라운드에서 새 버전을 빌드하고(실행 중인 앱과 다른 폴더에 빌드하므로 그대로 써도 됩니다), "다시 시작해서 적용"을 누르면 실행 파일을 바꿔 다시 엽니다.

## 실행

필요: Node 22+, Rust stable, pnpm, 그리고 설치·로그인된 Command Code CLI (`npm i -g command-code`, `cmd login`).

**설치 파일로 받은 컴퓨터에 CLI가 없으면** 첫 실행 때 "처음 설정"이 뜹니다. **자동 설치**를 누르면 nodejs.org의 Node.js LTS(체크섬 확인)와 npm의 `command-code`를 앱 데이터 폴더(`%LOCALAPPDATA%\ai.commandcode.cmdcgui\runtime`, 맥은 `~/Library/Application Support/ai.commandcode.cmdcgui/runtime`)에 받고, 이어서 브라우저 로그인으로 넘어갑니다. 시스템에는 아무것도 설치하지 않고 관리자 권한도 필요 없습니다. 직접 설치한 CLI가 있으면 그쪽을 먼저 씁니다. 나중에 다시 열려면 왼쪽 아래 버전 → **처음 설정**.

```bash
pnpm install
pnpm tauri dev
```

배포용 빌드 (설치 파일은 `src-tauri/target/release/bundle/`):

```bash
pnpm tauri build
```

폴더를 바로 열기:

```bash
cmdc-gui.exe D:\project
```

## macOS

맥용 앱은 GitHub Actions에서 만듭니다(맥 앱은 맥에서만 빌드되기 때문). Apple Silicon과 Intel 맥 모두에서 돌아가는 universal `.dmg` 하나가 나옵니다.

**받기**: 저장소의 **Actions → Build macOS → 최신 실행 → Artifacts**에서 `Command-Code-Desktop-macOS`를 내려받습니다. 직접 새로 만들려면 같은 화면에서 **Run workflow**를 누릅니다. `v0.5.0`처럼 버전 태그를 올리면 Releases에 초안으로도 붙습니다.

**설치와 첫 실행**: 이 앱은 Apple 개발자 서명이 없어서(ad-hoc 서명만 됨) 처음 열 때 macOS가 막습니다.

1. `.dmg`를 열고 앱을 **응용 프로그램** 폴더로 끌어 놓습니다.
2. 앱을 **우클릭 → 열기 → 열기**를 누릅니다. (또는 **시스템 설정 → 개인정보 보호 및 보안**에서 "그래도 열기")
3. "손상되었기 때문에 열 수 없습니다"가 나오면 터미널에서 한 번 실행합니다:

```bash
xattr -dr com.apple.quarantine "/Applications/Command Code Desktop.app"
```

**필요한 것**: 없으면 첫 실행의 "처음 설정"이 Node와 CLI를 앱 전용으로 받고 로그인까지 이어 줍니다. 직접 설치해 둔 Node 22 이상과 `npm i -g command-code`가 있으면 그것을 씁니다. Homebrew, nvm, volta로 설치한 node도 찾습니다(앱이 로그인 셸의 PATH를 읽음).

**맥에서 다른 점**
- 단축키는 Ctrl 대신 ⌘ (예: ⌘N 새 채팅, ⌘W 탭 닫기). 터미널 탭에서는 ⌘C/⌘V가 복사·붙여넣기이고, Ctrl은 터미널 그대로입니다.
- 계정 키는 macOS 키체인에 보관됩니다.
- 앱 업데이트는 새 `.dmg`로 합니다. (앱 안의 "앱 업데이트"는 소스 폴더에서 직접 빌드한 경우에만 쓸 수 있습니다.)

## 알려진 한계

- `cmd acp`가 처음 뜨는 데 10~20초 걸립니다(CLI 자체 시작 시간). 같은 폴더의 두 번째 대화부터는 연결을 재사용해 빠릅니다.
- ACP는 CLI와 설치된 mod가 노출하는 슬래시 명령만 보여 줍니다. `/usage`, `/config`, `/rewind` 등은 터미널 탭에서 쓰세요.
- 할 일 패널은 CLI의 `todos` 모드가 켜져 있어야 나옵니다 (`cmd mods enable todos -g`).
- DAG 패널은 노드 상태·의존성·검증만 보여 줍니다. ACP가 서브에이전트의 토큰 수를 전달하지 않아 노드별 토큰은 표시하지 않습니다.
- 터미널 탭은 계정을 바꾸면 새 CLI로 다시 시작합니다. 진행 중이던 TUI 대화는 `/resume`으로 이어 가세요. (채팅 탭은 대화가 그대로 이어집니다.)

## 실행 탭: 리서치부터 검증까지

채팅 안의 **실행** 탭에서 목표·완료 기준과 최대 반복(1~5회)을 입력합니다.
기존 ULW mod 없이도 앱이 ACP 세션을 만들어 역할별 실행과 검증 루프를 관리합니다.

| 명령 | 워크플로 |
| --- | --- |
| `/desktop-research 목표` | 공식 자료 조사 → 반증 → 종합 → 독립 검증 |
| `/desktop-team 목표` | 자료·대안·위험 독립 병렬 조사 → 상호 검토 → 종합 → 검증 |
| `/desktop-build 목표` | 리서치 팀 → 설계·코드 변경 → 회고 → 검증·수정 |
| `/desktop-taste 목표` | 프로젝트 취향·기존 패턴 확인 → 코드 변경 → 회고 → 검증·수정 |

명령은 설정 화면을 열며 **실행 시작**을 눌러야 추론을 시작합니다. 조사 역할은
계획 모드, 구현 역할은 현재 채팅 권한 모드로 동작합니다. 역할마다 별도 세션을
쓰고 선택한 모델·추론 강도를 복사합니다. 실행 탭은 그래프, 반복, 실패한 검증과
노드별 전체 결과를 보여 주며, 결과는 JSON으로 내보낼 수 있습니다.
기존 CLI ULW 도구가 만든 그래프는 별도의 **관찰** 영역에 표시합니다.

**프로젝트 Taste**에 저장한 취향을 후속 역할에 전달합니다. 코딩 실행의 회고가
만든 학습 후보는 에이전트 검증이 통과한 뒤 직접 반영할 수 있습니다. 이 기능은
명시적 선호·절차 재사용이며 Command Code의 `taste-1` RL이나 Hermes 자체가 아닙니다.
취향은 이 앱의 프로젝트별 로컬 저장소에 두며 기존 `.commandcode/taste/`를 수정하지 않습니다.

실행은 **현재 Command Code 계정**으로 과금됩니다. ChatGPT 구독을 연결하는 기능이
아닙니다. 검증 통과는 독립 에이전트의 근거 있는 JSON 판정이며 앱 자체가 명령의
진실성을 보증하는 것은 아닙니다. 오류·잘못된 검증 JSON은 성공 처리하지 않습니다.
중지하면 실행 중인 역할들을 취소하고 닫습니다. 앱 종료 후 자동 재개는 지원하지
않으므로 필요한 결과는 먼저 내보내세요.

정책 확인·현황·후속 우선순위는 [검토 보고서](docs/REVIEW-2026-10-31.md)에 있습니다.
개인 복수 계정 운영 관련 약관 제약과 비공개 요금 API 사용 범위 확인이 필요합니다.

오프라인 QA (외부 추론 없음):

```sh
bun scripts/qa/workflow.mjs
pnpm build
```

네이티브 UI QA는 `scripts/qa/desktop.html`과 `scripts/qa/native.ps1`을 사용합니다.
이는 실제 ChatView와 ACP request/receive 경로의 로컬 peer 검증이며 라이브 모델이나
Rust stdio 검증은 아닙니다. 증거·재현 조건은 `docs/evidence/2026-10-31/QA.md`와 `HANDOFF.md`에 있습니다.

## 범위

이미 설치하고 구독 중인 Command Code CLI를 감싸는 개인용 데스크톱 셸입니다. Command Code를 포함·재배포·재구현하지 않습니다. 사용자의 `~/.commandcode/auth.json`에서는 표시용 계정 이름만 읽습니다. 계정 추가 때는 앱이 만든 임시 폴더에 `cmd login`이 쓴 키만 자격 증명 관리자로 옮기고, 그 폴더는 바로 지웁니다.
