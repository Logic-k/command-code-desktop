COMMANDCODE DESKTOP · 확장 리서치

그래프보다 먼저, 근거와 복구

Tauri와 기존 실행기를 유지하고 조사에서 검토·제작까지 이어지는 작업대로 확장합니다. 권한과 종료, 실제 검사 증거를 먼저 고정합니다. [S1][S24][S25]

이번 산출물은 리서치와 AI 실행계획입니다. 제품 구현이나 출시 완료가 아닙니다. 모든 조사 모델은 ChatGPT 구독 경로로 고정했습니다.

직접 확인한 출발점

통과 문자열은 실행 증거가 아닙니다

아무 도구도 실행하지 않은 합성 결과가 그럴듯한 verifier JSON을 반환하면 현재 실행기는 통과했습니다. 실제 host 검사 영수증과 모델 판정을 나눠야 합니다. [S1][S24]

수정 전 교훈이 살아남습니다

첫 회고 뒤 구현을 수정하고 재검증해도 최초 학습 후보가 노출됐습니다. 후보를 최종 attempt·산출물 revision에 묶어야 합니다. [S1][S24]

정상인 기존 가드는 보존합니다

잘못된 JSON과 빈 근거 차단, 통제된 로컬 형제 실패의 취소·정리는 확인했습니다. 실제 provider 취소나 프로세스 회수의 증거로 확대하지 않습니다. [S1][S25]

정적 위험과 재현은 다릅니다

부모 권한 처리기의 자식 재사용과 IPC 단절 정리 분기는 후속 검사의 표적입니다. 실제 쓰기 탈출이나 고아 프로세스를 재현했다고 주장하지 않습니다. [S25][S26]

권고하는 선후 관계

구독 연동은 조건부입니다

공식 SIWC에는 로컬·오픈소스의 동의 기반 plan usage 경로가 있습니다. 신원 로그인과 추론 동의, 로컬과 hosted 제품, 안정 메서드와 app-server production 지원은 서로 다릅니다. [S2][S3][S4][S5]

제안: 실험 adapter를 별도로 만들고 인증·실효 모델·취소·갱신·비용 경로를 검증합니다. API-key fallback은 없으며, allowance-only를 보장할 수 없는 엄격 모드는 실행을 거부합니다. 보조 모델도 예외가 아닙니다. [S20][S21][S23]

결과를 기본으로, 그래프는 관계 탐색으로

결과 · 근거 · 활동 · 변경 · 관계를 나눕니다. 사용자는 출처와 반대 근거를 확인한 뒤 이 근거로 구현을 선택합니다. 그래프를 읽지 않아도 승인·검토·중지를 끝낼 수 있어야 합니다. [S24][S25][S28]

Taste는 최종 결과에 묶인 선호·절차·환경 사실의 재사용입니다. 후보별 근거, 승인, 철회가 필요하며 자동 RL이나 검증된 개선율로 부르지 않습니다. [S1][S9][S11][S12][S22]

방법과 남은 확인

공개 공식 원문·고정 코드와 로컬 실행 반례를 종합했습니다. 사용자 브라우저는 권한이 승인되지 않아 자료를 읽지 못했습니다. 다른 모델·API-key 추론·로그인·제품 변경은 하지 않았습니다.

정적 권한·프로세스 위험의 실제 효과, provider 동시성·취소, 계정 자격·credits, 라이브 품질·OS별 배포는 후속 게이트입니다. 출처·claim·시각·교정 결과와 정리 영수증은 조사 원장에 기록합니다.
