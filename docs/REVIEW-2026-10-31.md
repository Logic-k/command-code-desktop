# 정책 확인·현황·개발 방향 (2026-10-31)

## 판단

앱이라는 이유만으로 정책 위반이라고 볼 근거는 없다. Command Code가 공식적으로
2026년 10월 6일 공식 발표에서 `cmd acp`를 외부 클라이언트용으로 제공하므로, 기존 CLI를 실행하고 표준 ACP로
화면을 붙이는 기본 구조는 공식 통합 방식과 부합한다. 다만 이것은 앱의 모든
기능에 대한 승인이나 법률 의견이 아니다.

**확인된 충돌 조건:** Command Code 약관은 개인당 한 계정만 허용하며, 우회 여부와
무관하게 한 개인이 여러 계정을 운영하는 것을 금지한다. 현재 앱은
`src-tauri/src/accounts.rs`와 `src/main.ts`에서 여러 계정의 추가·전환을 지원한다.
기능 존재만으로 실제 위반을 입증하지는 못하지만, 같은 사람이 복수 개인 계정을
운영하거나 한도를 피해 전환하면 해당 조항과 충돌한다. 실제 계정 소유·계약 상태는
확인하지 않았다. 요청대로 인증·계정 동작은 변경하지 않았다.

**확인 필요:** `src-tauri/src/billing.rs`는 공식 ACP가 아닌 `/alpha/` HTTP API를
직접 호출한다. 문서에 공개된 ACP와 달리 이 API의 제3자 사용 허용 범위는 이번
근거만으로 확정할 수 없다. 약관의 자동 접근 제한·역공학 제한과 함께 제공자에게
확인할 사안이다. 토큰 추출·재배포를 일반적으로 허용한다고 해석하면 안 된다.

공식 npm에서 사용자가 동의해 CLI를 설치하는 기존 setup 방식과, CLI 바이너리를
앱에 넣어 재배포하는 것은 구분해야 한다. 앱 자체 MIT 라이선스가 CLI나 상표까지
허가하는 것은 아니다. 외부 모델 업체 정책 준수도 Command Code 약관상 별도 의무다.

## ChatGPT 구독 구분

이번 개발 세션의 환경은 `PI_PROVIDER=chatgpt-subscription`으로 확인했다.
다른 모델 에이전트나 Command Code 유료 추론을 QA용으로 실행하지 않는다.
이 사실은 **개발 대상 앱의 과금 경로가 ChatGPT 구독이라는 뜻이 아니다.**
현재 앱은 Command Code 계정과 CLI를 사용하는 제품이다.

OpenAI 공식 문서는 ChatGPT 로그인으로 Codex CLI 등을 사용하는 경로를 안내한다.
ChatGPT 구독을 일반 OpenAI API 키나 Command Code 크레딧으로 치환할 수 있다는
근거는 아니다. 앱에서 ChatGPT 구독을 지원하려면 공식 Codex 클라이언트/SDK의
인증·약관·사용량 체계를 별도 어댑터로 연결하는 후속 작업이 필요하다.

## 구현 방향

기존 ACP와 그래프를 재사용하되 앱이 관리하는 워크플로를 별도로 표시한다.
채팅/실행 탭에서 목표, 역할별 의존성, 결과, 검증 실패, 다음 반복을 확인한다.
리서치 팀은 독립 조사 → 반증 → 종합으로 구성하고, 조사만 하는 실행과
구현까지 진행하는 실행을 명확히 나눈다. 자동 반복은 최대 횟수를 사용자가
정하며 취소·실패 시 멈추고, 검증 응답이 잘못되면 성공으로 간주하지 않는다.

이번 앱의 Taste는 모델 가중치 학습이 아니라 프로젝트 선호와 성공한 절차의 재사용이다.
사용자가 편집·저장한 취향을 후속 작업 프롬프트에 전달하고, 회고는 검증된
근거와 재현 명령을 남기도록 한다. Hermes의 자기 개선은 재사용 가능한 skills와
memory에 가깝다. Hermes 고유 기능을 그대로 이식했다고 주장하지 않는다.
코딩 실행의 회고 단계가 구조화된 학습 후보를 만들고, 에이전트 검증 통과 후
사용자가 선택해야 다음 실행의 취향에 반영한다. Command Code 자체의 `taste-1`
신경기호 모델/RL 기능과는 별개이며 그것을 재구현한 것이 아니다.

## 오픈소스 활용

- 기존 MIT 앱, xterm.js, DOMPurify, 표준 ACP를 우선 재사용한다.
  현재 그래프 규모에는 기존 SVG 렌더러로 충분해 그래프 라이브러리를 추가하지 않는다.
- Hermes Agent의 skills 패턴과 Agent Skills 표준을 참고한다. Python 에이전트
  전체를 Tauri에 내장하면 런타임·인증·업데이트가 이중화되므로 이번에는 넣지 않는다.
- LangGraph 같은 외부 오케스트레이터는 durable worker/서버가 필요한 단계에서
  평가한다. 로컬 앱의 작은 DAG를 위해 서버와 새 모델 과금을 추가하지 않는다.
- 코드/스킬을 실제로 가져올 때는 해당 버전 LICENSE와 출처를 함께 보존해야 한다.
  이번 구현은 아래 자료의 설계 개념을 참고하며 외부 소스 코드를 복사하지 않는다.
