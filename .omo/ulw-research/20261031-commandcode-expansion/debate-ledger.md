# Debate ledger

## D1: More agents versus reliable evidence
Claim: parallel specialists improve coverage.
Attack: same-model consensus and well-formed prose do not prove truth; V-PROOF
passes without an actual tool. Hidden visualizer calls can also violate billing.
Disposition: retain bounded roles, but require source/receipt coverage and compare
against a same-budget single-agent baseline. No predicted quality gain.
Claims: C1 C6 C12. Evidence: S1 S20 S21.

## D2: Replace orchestration versus preserve the runner
Claim: LangGraph/Temporal already solve persistence and interruption.
Attack: WebView/native/runtime boundaries and opaque external effects remain.
Counterattack: a custom scheduler can grow into a second framework.
Disposition: single-writer Rust transactions plus current TS runner; manual recovery
first. No distributed lease or automatic effect replay in the minimum plan.
Claims: C3 C7 C10. Evidence: S8 S15 S16, durability lane pinned source comparisons.

## D3: Subscription support versus production eligibility
Claim: official SIWC permits some ChatGPT-plan inference in third-party local apps.
Attack: identity-only login is not inference consent; preview/support scope,
effective model and credits still need verification. Internal token methods are
not a substitute for the documented path.
Disposition: separate experimental adapter work package with explicit go/no-go.
No silent API-key/provider fallback and no production-default promise.
Claims: C5 C6. Evidence: S2 S3 S4 S5 S20 S23.

## D4: Autonomous learning versus provenance and stale candidates
Claim: reflection can improve future work.
Attack: the first reflection survives correction; it can also contain unsupported
instructions. Skill standards do not enforce permissions or effectiveness.
Disposition: final-revision-bound candidates, individual approval, reversible
versions and offline evaluation before any efficacy claim.
Claims: C2 C8 C12. Evidence: S1 S9 S11 S12 S22 S24.

## D5: Graph-first versus result-first workbench
Claim: graph makes the loop inspectable.
Attack: a large graph is a poor default for comparing evidence and reading artifacts.
Disposition: results/evidence table first, timeline for actual events; explicit
execution DAG and claim relation graph are optional separate projections.
Claims: C9. Evidence: workspace lane documented contracts; S24 S25 S28.
